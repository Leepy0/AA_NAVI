# AA_NAVI (시험용)

Android Auto 연결 직후 AA 화면에 목적지 추천 팝업을 띄우고, 탭 한 번으로 TMAP·네이버 지도 안내를 시작하는 앱의 실현 가능성 시험판. 결과만 설계에 반영하고 이 코드는 버린다.

## 설치

1. `gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`를 휴대폰에 설치.
2. Android Auto 설정 → 버전 항목 10번 탭 → 개발자 설정 → **알 수 없는 출처** 켜기.
3. 휴대폰에서 앱을 한 번 열고 알림 권한 허용. 앱 프로세스가 살아 있어야 연결을 감지한다.

## 시험 항목

| # | 어디서 | 무엇을 | 확인할 것 |
|---|--------|--------|-----------|
| 1 | 휴대폰 화면 | `TMAP rGoX` / `TMAP goalx` / `네이버 nmap` 버튼 (AA 연결 상태) | AA 화면에 확인 없이 안내가 바로 뜨는가 |
| 2 | AA 연결 순간 | 자동 heads-up 팝업 | 팝업이 뜨는가, 얼마나 가리는가, 버튼이 보이는가 |
| 3 | 팝업 본문 탭 | `ACTION_NAVIGATE geo:` | 마지막에 쓴 내비가 받아 바로 안내하는가 (TMAP, 네이버 각각 먼저 한 번 실행해 두고 시험) |
| 4 | 팝업 `TMAP(폰)` 버튼 | 휴대폰 Activity가 `tmap://` 호출 | 백그라운드 실행 차단 없이 열리는가 |
| 5 | 팝업 `TMAP(차앱)` 버튼 | 이 앱 차 화면을 연 뒤 `tmap://` 호출 | 4와 비교 |
| 6 | AA 앱 목록 → AA 내비 시험 | 목록의 각 줄 | 3~5를 팝업 없이 반복 |

결과는 휴대폰 앱 화면 아래 기록과 `adb logcat -s AANAVI`에 남는다.
